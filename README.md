### weather-sraper  
Структура проекта:  
weather-sraper

/dev

|`main.py` # основной файл в котором запущен цикл скрапинга`
|-
|`enter_point.py` # точка входа, запуск и проверка работы`
|
|`artifacts.py` # рисует график на основании статистики` 
|`Skrapper.py`# файл парсинга сайта и получения данных
|`weather1.csv` # файл куда сохраняются данные

       

  
  
### Использование: 
**Запустите файл enter_point.py:**  
убедитесь, что все корректно работает и что он действительно собирает данные.

**Запустите файл artifacts.py:**  
появится новый файл weather_trend.png в котором будет отображен график
